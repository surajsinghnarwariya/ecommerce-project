# 🛒 Amazon Clone (E-commerce Website)

A full-stack e-commerce web application inspired by Amazon.  
Users can browse products, add items to cart, and proceed to checkout.

---

## 🚀 Live Demo
🔗 https://ecommerce-project-lac-iota.vercel.app

## 📂 GitHub Repository

## 🛠 Tech Stack

### Frontend
- React.js
- JavaScript (ES6)
- CSS / Inline Styling

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Tools & Deployment
- Git & GitHub
- Vercel (Frontend)
- Render (Backend)

---

## ✨ Features

- 🛍 Product listing
- 🔍 Search bar UI
- 🛒 Add to Cart functionality
- 💾 Cart stored using Local Storage
- 🔄 Dynamic data fetching from backend
- 📱 Responsive design
- 🔗 Routing using React Router
